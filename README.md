# Solo MMO RPG — builds & patches

This repository only holds **game builds and update files** for Solo MMO RPG.
There is no source code here.

- `latest.json` — read by the game to check for updates
- **Releases**
  - `app-v*` — full app builds (Android `.apk`, Windows `.exe`)
  - `patch-v*` — small in-game patches (`.pck`), downloaded and verified by the game itself

## Installing on Android
Download the newest `SoloMMO-*.apk` from Releases, open it, and allow installing from this source.
Later versions install over the old one — your save stays on the device.
